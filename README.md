Streamlit-приложение для прогнозирования типа осадков (сухо/дождь/снег) с использованием мультиклассовой модели LightAutoML и актуальных данных Open-Meteo.

# Прогноз осадков (Weather Prediction App)

Приложение на Streamlit, которое предсказывает тип осадков (сухо, дождь или снег) на текущий день на основе данных о погоде за последние дни.

## О проекте

В основе приложения лежит мультиклассовая модель машинного обучения, обученная с помощью библиотеки **LightAutoML**. Модель анализирует лаговые признаки (осадки и их категории за предыдущие 3 дня, день недели, месяц) и выдает вероятности для трех классов:
- **0** — Осадков не ожидается (сухо)
- **1** — Ожидается дождь
- **2** — Ожидается снег

Для получения актуальных фактических данных о погоде используется открытый API **Open-Meteo** (без необходимости регистрации и API-ключей).
